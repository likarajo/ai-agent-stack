# Issue triage conventions

## Labels
- `auth`, `billing`, `ui`, `docs`, `infra`, `test`
- Severity: `p1`, `p2`, `p3`
- Type: `bug`, `enhancement`

## Triage checklist
1. Search open issues for the same symptom text
2. Confirm state is still `open`
3. Assign severity using the login timeout runbook when auth-related
4. Prefer one assignee; leave unassigned only for enhancements without an owner
5. Write a short triage report: summary, severity, recommended next step

## Report template
```
# Triage report
- Scope: <what you searched>
- Matches: <issue ids and titles>
- Severity call: <p1|p2|p3 and why>
- Next step: <one concrete action>
```
